# Documentation

## Purpose

This folder preserves the engineering reasoning and delivery history behind Atlas.

## What Belongs Here

- Architecture Decision Records in `adr/`.
- Grounded engineering journal entries in `journal/`.
- Sprint plans, outcomes, and retrospectives in `sprint-notes/`.
- Documentation that supports implementation and operation.

## What Does Not Belong Here

- Invented decisions, results, dates, or metrics.
- Deployment configuration or executable scripts.
- Unsorted screenshots or binary runtime data.
