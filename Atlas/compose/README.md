# Compose

## Purpose

This folder provides the future entry point for local multi-container deployment.

## What Belongs Here

- The Atlas Docker Compose definition.
- A safe example of required environment variables.
- Compose-specific setup and operating notes.

## What Does Not Belong Here

- Secrets or populated environment files.
- Dockerfiles or image build contexts.
- Splunk application configuration.
- Unrelated development tooling.
