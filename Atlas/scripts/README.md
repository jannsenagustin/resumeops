# Scripts

## Purpose

This folder is reserved for repeatable Atlas development and operational automation.

## What Belongs Here

- Scripts required by an active implementation workflow.
- Validation, setup, or maintenance automation.
- Usage notes for every introduced script.

## What Does Not Belong Here

- One-off commands with no reuse value.
- Secrets, credentials, or environment-specific data.
- Generated output or runtime logs.
- Premature automation without a current project need.
