# Docker

## Purpose

This folder is reserved for Docker image build assets required by Atlas.

## What Belongs Here

- Future Dockerfiles with an immediate deployment purpose.
- Image-specific configuration and documentation.
- Small build-context files required by those images.

## What Does Not Belong Here

- Compose orchestration definitions.
- Runtime data, logs, or secrets.
- Unused image experiments.
- Splunk configuration created before its implementation sprint.
