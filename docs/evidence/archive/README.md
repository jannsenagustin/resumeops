# Evidence Archive

## Purpose

Retain superseded or historical Atlas evidence that remains useful for
engineering reference but no longer represents the current implementation.

## Archiving Guidance

- Preserve the original filename or document any rename.
- Record the source milestone and reason for archiving.
- Keep enough context to explain what the artifact proved at the time.
- Do not use archived evidence to support current validation claims.

No evidence has been archived as part of the initial repository structure.
