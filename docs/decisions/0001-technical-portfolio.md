# ADR 0001: Technical Portfolio Instead of Chronological Resume

## Status

Accepted

## Context

ResumeOps began as a resume-style website but is intended to demonstrate technical ability and engineering thinking.

## Decision

Prioritize technical case studies, documentation, architecture, and engineering work rather than reproduce the user's full chronological employment history.

## Consequences

Technical work becomes easier to evaluate. Nontechnical employment is not erased but is represented through the Career Journey where relevant.
