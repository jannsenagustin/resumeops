# ResumeOps Engineering Roadmap

The roadmap separates completed platform foundations from active and future engineering work. Planned items describe intent, not delivered capability.

### Completed

- GitHub Pages static deployment
- Reusable component foundation

- Sprint 4A homepage architecture
- Sprint 4B Enterprise Experience
- Sprint 4C Hero redesign
- Sprint 4D brand and content refinement

### In Progress

- ResumeOps Engineering Platform

## Phase 2 — Engineering Projects

### In Progress

- **Codename:** Atlas
- **Current stage:** Sprint 6B — Infrastructure
- **Status:** In Progress

### Planned

- Detection Engineering
- Splunk App Development

Each project should mature into an Engineering Case Study covering context, implementation, validation, troubleshooting, decisions, lessons learned, and future improvements where evidence exists.

## Phase 3 — Technical Publishing

### Planned

- Architecture Decision Records for significant platform choices
- Release notes for meaningful milestones

- Add a verified downloadable resume asset.

## Status Reference

- **Completed** — implemented and validated.
- **In Progress** — active work with incomplete scope.
- **Planned** — intended work that must not be presented as complete.
- **Future** — direction without a committed delivery schedule.
