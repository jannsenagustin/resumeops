# Atlas Design

This directory contains approved visual-direction documentation for Project
Atlas. It records the design intent that implementation must follow; it is not
an implementation record and does not claim that the documented interface
exists.

## Governing References

Design decisions inherit the engineering constraints in the
[Project Atlas Engineering Manifesto](../../ATLAS_PRINCIPLES.md). The manifesto
is the engineering constitution; this directory translates those principles
into a stable visual direction.

The [Documentation Experience Architecture](../dea/README.md) governs how
readers discover, understand, verify, and inspect Atlas. Design must express
that architecture without changing its ownership, vocabulary, or approved
reading model.

[Milestones](../milestones.md) remain the canonical record of project state.
Visual treatments may expose milestone status, but they must never invent,
upgrade, or obscure that status.

## Approval and Implementation

Design direction is approved before implementation begins. Implementation
follows design approval—never the reverse. Application changes require their
own reviewed implementation phase and validation; the documents in this
directory do not authorize or record those changes.
